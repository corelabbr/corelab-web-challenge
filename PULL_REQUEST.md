# Solução

O objetivo dessa solução foi implementar mais fielmente as funcionalidades e design propostos no teste, usando apenas as tecnologias sugeridas, da forma mais rápida, exuta e simples possível.

# Executando

Obviamente, é necessário instalar as dependencias do reposítório:

```
npm run install
```

Esse repositório também depende de uma apliação backend criada para o mesmo teste. https://github.com/Imenatrix/corelab-api-challenge ou https://github.com/Imenatrix/corelab-api-challenge-php. Clone um desses repositórios, siga as instruções de execução e execute o servidor. Quando o servidor estiver aberto, é necessário que se coloque a URL onde o servidor está rodando como uma variável de ambiente nesse projeto (VITE_API_URL) tal qual se encontra no exemplo incluso.

Para executar esse componente do projeto, use o comando:

```
npm run dev
```

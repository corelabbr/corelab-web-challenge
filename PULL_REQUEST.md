## Descrição do Projeto

Eu utilizei **Vite** e **React JS** para desenvolver o desafio proposto, optando pelo **TailwindCSS** para criar o design de forma rápida e eficiente.  

Considerando a dimensão do projeto, escolhi usar o `useContext` em vez de bibliotecas mais complexas como **MobX** ou **Redux**, acreditando que essa abordagem seria mais adequada e simplificada para o escopo do desafio.  

Segui as boas práticas do **React**, criando componentes reutilizáveis e bem estruturados para garantir um código mais escalável, de fácil manutenção e leitura.  

Organizei o projeto com uma estrutura de pastas simples e intuitiva, separando adequadamente elementos como **APIs**, **imagens** e **componentes** para facilitar o acesso e manter o código organizado.  

Embora tenha considerado implementar a abordagem **MVVM**, decidi que poderia desviar do escopo do desafio, então optei por uma estrutura mais direta e eficiente.
